# 影之刃零｜魂式菜单 SoulsMenu

**战斗中换武器、换戒指，让临场换装更顺手。**

如果你习惯《黑暗之魂 3》的菜单换装方式，SoulsMenu 会为《影之刃零》带来更熟悉的操作体验：战斗中进入主武器和戒指／饰品列表，按需要更换装备；菜单是否暂停、能否移动、详情是否隐藏，都可以自己决定。

## 主要功能

- **战斗换武器、换戒指**：进入主武器或饰品列表，使用游戏原有的换装接口操作。饰品支持更换与卸下，保留原有槽位解锁、剧情锁、重复装备及同类饰品数量限制。
- **菜单开着，也能移动**：不暂停模式下，WASD／左摇杆继续控制人物，视角保持锁定；鼠标／十字键用于选择菜单物品。
- **更直观的上下槽位**：主武器与影之武装的当前／备用槽位在菜单中上下对调，当前使用的装备显示在上方。
- **右侧详情，一键收起**：菜单内单按 L3，在松开时隐藏／显示右侧详情；键盘默认 F6。隐藏时背景默认完全透明，透明度可自行调整。
- **常用武器，放在熟悉的位置**：主武器与影之武装二级列表保持固定顺序。Ctrl＋方向键，或按住 L3＋十字键交换相邻位置，调整后自动保存；排序组合键不会误触隐藏。
- **武器二级菜单 Esc 直退**：在主武器／影之武装选择界面，按 Esc 退出整个菜单。
- **切换能力可选**：更换当前主武器后，在关闭菜单并完成加载时，请求游戏原生的当前槽切换／拔刀能力。是否激活仍由游戏状态决定，备用武器和饰品不会触发该请求。

## 19 项设置，按习惯调整

暂停或不暂停、战斗换戒指、菜单内移动、上下槽位映射、切换能力、固定排序、隐藏按键、背景透明度和摇杆死区，都可以通过本地 INI 修改。

首次启动后，配置文件位于：

```text
%LOCALAPPDATA%\ProjectPBZ\Saved\PBZSoulsMenu.cfg
```

用记事本以 UTF-8 编辑，保存后完全重启游戏。更新不会覆盖已有个人设置；旧版配置缺少的新选项会使用默认值。绿色屏幕说明默认关闭。

## 默认操作

| 操作 | 按键 |
| --- | --- |
| 菜单内移动 | WASD／左摇杆，不暂停模式生效 |
| 选择菜单物品 | 鼠标／十字键 |
| 隐藏／显示右侧详情 | 单按 L3（松开时触发）／F6 |
| 调整武器列表位置 | Ctrl＋方向键／按住 L3＋十字键 |
| 武器二级菜单直接退出 | Esc |

## 安装与下载

需要先安装 **PBZModLoader**。关闭游戏后，选择一种安装方式：

- **Nexus／手动安装**：解压 `PBZ_SoulsMenu-0.5.1-Nexus-Manual.zip`，将 `ProjectPBZ` 合并到游戏根目录。
- **小黑盒**：导入 `PBZ_SoulsMenu-0.5.1-Heybox.zip`，启用并部署。PhantomBladeZero 扩展还会检查其共用的 UE4SS 前置。

两个包选择一个即可。安装后完整重启游戏，不使用 Alt+F5 热重载。

适配目标：Steam build `26367565`。游戏更新或其他修改相同菜单方法的 Mod 可能产生冲突。开发阶段的模拟检查不替代游戏内验收，建议换装后确认饰品属性、效果及界面同步。
